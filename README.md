# Agentic GTM Workflows

Free, open source skills for Claude that run go-to-market (GTM) work for you.

Each skill is a folder with clear steps that Claude follows every time. You connect your tools, fill in a short setup file, and Claude does the busy work. A human still checks anything that goes out under your name.

## Skills

| Skill | What it does |
|---|---|
| [LinkedIn Comment Engine](skills/linkedin-comment-engine/) | Finds 20-30 LinkedIn posts a day where your buyers are reading, drafts a smart comment for each one, and schedules only the comments you approve. |

More skills are coming.

## How to use a skill

1. Open the skill's folder and read its README.
2. Connect the tools it lists (most are one-click connectors in Claude).
3. Have your own inputs ready (each skill's README says what it needs, like your ICP or your expertise). Nothing about your business ships with these skills.
4. Add the skill folder to Claude (Claude app: upload it as a skill; Claude Code: copy it into `.claude/skills/`).
5. Ask Claude to run it, or put it on a schedule.
