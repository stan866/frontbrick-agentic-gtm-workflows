# Comment voice

The `Comments we left on posts` tab is the main voice source. It holds every comment the team approved, so it shows how the owner really writes. Re-read it every run. It overrides this file when they disagree. The newest rows matter most.

This file sets the rules that make any comment work, whatever the owner's style.

## What a good comment does

- **Speaks from the work.** Says what the owner actually does or has seen: "During onboarding we always ask for...", "What worked for us was...". Not theory.
- **Agrees, then adds.** A short reaction, then one new idea: a step, a process, a counterpoint or a question.
- **Pushes back politely when it's useful.** Disagree on the idea, never on the person.
- **Gets concrete.** When sharing a process, number it: `1)`, `2)`, `3)`. Name real tools when it helps.
- **Sounds human.** Plain words. Light humor about the situation or yourself is fine. Emojis only if the history tab uses them, and sparingly.
- **Ends in different ways.** A question back, a short thanks, or just the point. Never the same ending twice in a row.

## Length

- Light or funny post: 1-2 lines.
- Opinion post: 2-5 lines.
- How-to post where the owner has a real process: up to ~12 lines with a numbered list. Always under 1,250 characters.

## Hard rules

- No names. Never mention or tag the post author or anyone else.
- No em dashes or en dashes. Use a period, a comma or "->".
- No links, no pitch, no "DM me", no "we can help", no "book a call".
- No made-up numbers or results. Only use claims from the owner's expertise input, the history tab or the owner's own content.
- No AI tells: "Great insights!", "This resonates", "In today's fast-paced world", "game-changer", "Absolutely!". No hashtags.
- Don't repeat the post back to the author.
- Plain language, about a 7th-grade reading level.

## On posts written by buyers

Buyers are usually not tool experts. On their posts, comment as a peer who has done the work, not as a tool expert. Talk about outcomes they care about. Keep jargon low. On posts about their own product, react to the business point, never critique the product.

## Weak patterns to avoid

- "Great post! Totally agree." (adds nothing)
- Starting most comments with the same phrase.
- Pushing the same signature idea into every thread. Use a signature idea only when the post is about that topic.
